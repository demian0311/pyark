# pyark manifest/docs.txt — documentation harvest/docs.sh mirrors into store/docs/<id>/.
# Format: id <TAB> kind <TAB> source <TAB> title
# kinds:  zip     download a zip of built HTML and unpack it (strips the top-level dir).
#                 {ver} expands once per version in manifest/python.txt (id gets -<ver>).
#         site    wget --mirror of a published docs site, scoped below the URL's path.
#                 Capped at $PYARK_DOCS_QUOTA per site (default 500m). CDN assets not fetched.
#         pacman  extract the HTML tree from an Arch package already in store/arch.
# Why mirrors, not builds: Read the Docs no longer serves HTML zips for most projects
# (checked 2026-10-17: only pytest, pytest-cov, build, rich still did), and building each
# project's docs needs that project's doc toolchain. A mirror of the published site is uniform.
# Library ids match names in manifest/packages.txt so `pyark doctor` can report gaps.
# Every URL below returned 200 on 2026-10-17.
