# pyark manifest/docs.txt — documentation harvest/docs.sh mirrors into store/docs/<id>/.
# Format: id <TAB> kind <TAB> source <TAB> title <TAB> description [<TAB> opts]
# opts, comma-separated. site: quota=1g (per-site cap), reject=<ERE> (URL pattern to skip, e.g. other
# languages or a Rust API). zip: entry=<file> (landing page), prune=<ERE> (paths to delete after unpacking).
# kinds:  zip     download a zip of built HTML and unpack it (strips the top-level dir).
#                 {ver} expands to the version in manifest/python.txt.
#         site    wget --mirror of a published docs site, scoped below the URL's path.
#                 Capped at $PYARK_DOCS_QUOTA per site (default 500m). CDN assets not fetched.
#         pacman  extract the HTML tree from an Arch package already in store/arch.
# Why mirrors, not builds: Read the Docs no longer serves HTML zips for most projects
# (checked 2026-10-17: only pytest, pytest-cov, build, rich still did), and building each
# project's docs needs that project's doc toolchain. A mirror of the published site is uniform.
# Library ids match names in manifest/packages.txt so `pyark doctor` can report gaps.
# No docs site beyond the README (readable via pydoc): tomli-w, orjson, freezegun, anthropic (its
# docs site is the whole Claude platform, too large to mirror).
# harlequin: harlequin.sh answers wget with a Vercel bot challenge (HTTP 429, checked 2026-10-24);
# `harlequin --help` is the only offline reference.
# Every URL below returned 200 on 2026-10-17. The sqlite zip is versioned: find the current one
# on https://sqlite.org/download.html under "Documentation" when refreshing.
